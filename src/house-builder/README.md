# House builder source (not served as a page)

- `gen.py` draws the isometric houses and writes the design file `Main.dc.html` from `template2.html`.
- `build_site.py` turns `Main.dc.html` into the builder block on the homepage (between the `builder:start` / `builder:end` markers in `/index.html`).

Paths inside the scripts point to the working folders used when building; adjust before running.
